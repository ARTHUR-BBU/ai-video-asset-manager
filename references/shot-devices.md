# Shot Construction Devices

These devices come from production failures. Use them to remove freedom the model will otherwise abuse.

## 1. Speech Count Lock
State the exact number of words and the exact line.
Example: “The take contains exactly three words: ‘Pull it, Oli.’”

Without this the model inserts mumbles, extra dialogue or foreign language.

## 2. Height / Scale Ruler
Never use relative adjectives alone.
Bad: “Horace is taller than Cal”
Good: “Horace’s eye-line sits at the level of Cal’s mouth”

## 3. Off-Screen Action Negative List
When an important action happens outside the frame, list what must not appear.
Example: “Oli kicks the door. No limb, no shadow, no reflection of the kick enters the frame.”

## 4. Asynchronous Reaction Rule
Two or more characters reacting to the same event must never move in perfect sync. Synchronised reactions read as animation.

## 5. Geometry Anchor
Always tie the character to a concrete spatial reference inside the location asset.
Bad: “the hero stands in the room”
Good: “the hero stands at the lamp, facing the door”

## 6. Period Hard Lock
Write the year as a hard rule, not atmosphere.
Example: “Nothing in frame is newer than 2011. No smartphones, no modern cars, no glowing screens.”
