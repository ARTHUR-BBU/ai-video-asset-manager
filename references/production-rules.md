# Full Production Rules Checklist

Derived directly from the Higgsfield open-source pipeline.

## The Five Non-Negotiable Rules

1. **Assets first**  
   Nothing generates until every face, place and prop is locked.

2. **Describe everything, every time**  
   The model has no memory between generations.

3. **Change one thing at a time**  
   Surgical iteration only. One line changes, the rest stays word-for-word.

4. **Give the model less freedom**  
   A corner, not a room. A map, not guesswork. Anchors over open descriptions.

5. **Shot won’t land? Simplify the shot, not the words**  
   After 10–15 iterations, split the shot, remove an action or change the angle.

## Supporting Practices

- Maintain a version log for every shot (version, exact change, pass/fail).
- Stress-test every character state asset with 10 generations across poses and lighting.
- Generate empty location walk-through videos to force volumetric consistency.
- Pre-record all music and feed the actual audio file as the performance.
- Assign mouth ownership explicitly for any singing or speaking performance.
- For impossible physical contact, film real motion reference on phone and overlay assets.
