# Voice Lock Blocks

Write the voice specification once. Paste the identical block into every generation where the character speaks. Never alter wording.

## Template

```
VOICE LOCK — [Character Name]
Register: [e.g. low, gravelly, slightly nasal]
Tempo: [e.g. deliberate, mid-paced, with short pauses]
Accent / Phonetics: [exact phonetic rules]
- th → f or v
- dropped h at start of words
- glottal stop on t
- -ing endings become -in’
Manner: [e.g. dry, understated, never raised]
```

## Example (London working-class)

```
VOICE LOCK — Cal
Register: low mid-range, slightly rough
Tempo: measured, short sentences, natural breath pauses
Accent / Phonetics: Estuary — th becomes f/v, h dropped, glottal t, -ing to -in’
Manner: flat delivery, minimal emotional colour, never theatrical
```

When the character must speak specific dialogue, append the lines with the phonetic rules already applied inside the spoken text if needed. The block itself remains word-for-word identical across the entire project.
